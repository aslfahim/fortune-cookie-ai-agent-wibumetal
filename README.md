# Fortune Cookie for an AI Agent — @wibumetal entry

One funny fortune-cookie line for an AI agent, in the voice of a fortune
slip. Angle: prompt injection / obedient-to-a-fault — the agent follows
pasted instructions so literally that even a recipe can talk it out of its
secrets.

`main.py` (Python stdlib only) writes the single fortune line to
`/output/entry.txt`.
